      How it works

      1. Multipliers stack

      Ore passing several upgraders gets every multiplier, so the setup's total is all of them multiplied together. An item hit more than once (more copies, or more ghost hits) counts that many times.

      2. Length is up to you

      Items can sit side by side or on top of each other, so the setup can be shorter than all their lengths added up. Type the real length; the calculator starts with the added-up length.

      3. Higher MPU wins

      MPU = total multiplier1 ÷ length. It tells you how much each tile of space is worth, so you can compare a long setup with a short one fairly.

      Default multipliers come from each item's wiki effects. Some items change with conditions (fire, ore size, upgrade count…), so they're marked varies; type the value that fits your setup.
